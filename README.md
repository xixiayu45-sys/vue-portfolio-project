# Vue 个人作品集项目

这是一个使用 Vue 3 和 Vite 构建的个人作品集网站。  
该项目用于展示我的前端开发能力、项目经验、响应式页面设计能力，以及基础的全栈开发实践。

## 功能特点

- 个人主页展示，包括个人介绍
- 项目作品展示模块
- 支持桌面端和移动端的响应式布局
- 联系方式展示模块
- 使用 Vue 组件构建现代化页面
- 包含本地数据或与后端相关的 SQL/server 实践内容
