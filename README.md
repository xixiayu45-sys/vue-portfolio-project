# Vue 个人作品集项目

这是一个使用 Vue 3 和 Vite 开发的个人作品集网站，用于展示个人介绍、项目经历、技术栈和联系方式。

## 在线预览

在线访问：https://your-deploy-url.vercel.app

## 项目功能

- 个人主页展示
- 项目作品展示
- 联系方式展示
- 响应式页面布局
- Vue 组件化开发
- 前端页面与后端/数据库练习内容

## 技术栈

- Vue 3
- Vite
- JavaScript
- HTML5
- CSS3
- Node.js
- MySQL
- GitHub
- Vercel

## 本地运行

安装依赖：

```bash
npm install
```

启动项目：

```bash
npm run dev
```

打包项目：

```bash
npm run build
```

预览打包结果：

```bash
npm run preview
```

## 项目亮点

- 使用 Vue 3 搭建单页面个人作品集网站
- 使用 Vite 提升开发和构建效率
- 页面结构清晰，适合展示个人信息、项目经历和联系方式
- 采用组件化开发方式，提高代码可维护性
- 实现响应式布局，适配桌面端和移动端访问
- 使用 GitHub 管理项目代码，并通过 Vercel 部署上线

## 项目收获

通过该项目，我练习了 Vue 项目的搭建、组件拆分、页面布局、响应式设计、GitHub 代码管理以及前端项目部署流程，对完整的前端项目开发流程有了更清晰的理解。
